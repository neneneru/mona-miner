# Mona Miner

## 今北産業

- Monacoin（Lyra2REv2）向けの CUDA 13.4 対応の NVIDIA CUDA マイナーです。
- SM120 は RTX 5090、SM89 は RTX 4070 Ti で実機検証を完了しています。
- 改善内容や検証結果などの詳細は、各バージョンの README に記載しています。

## v2（調整中）

Public v2 / SM120 は、公開後に確認された console / launcher UX の修正と再検証を行っています。
v2.0.0 の配布は一時停止しています。新規利用は [Public v1](v1/) を利用してください。

## [v1](v1/)

- **対応環境**: SM120（RTX 50 シリーズ） / SM89（RTX 40 シリーズ）
- **手数料**: なし
- **パフォーマンス**:
  - SM120: 約 396 MH/s（約 440 W 制限 / 旧 ccminer 比 約 +20%）
  - SM89: 約 160 MH/s（約 185 W 制限 / 旧 ccminer 比 約 +23%）

## 対応範囲

- 対応アルゴリズムは **Lyra2REv2 のみ** です。
- 動作対象の判定は、製品名ではなく GPU アーキテクチャ（SM バージョン）を基準に行われます。
- 同一の SM であっても、すべての機種・個体での動作を保証するものではありません。

## 共通ポリシー

- 隠し / 予備プールへの接続、テレメトリ送信、自動更新確認などのバックグラウンド機能はありません。
- Mona Miner 自体が GPU の電力制限・電圧・クロック・ファン設定等を変更することはありません。
- 必要なハードウェア設定やチューニングは、ユーザー自身の管理下で外部ツール等を用いて行ってください。
